# 한 수학 지도 (one-math)

초등학교 1학년부터 고등학교 1학년 공통수학까지, **학교 수학 전체의 뼈대와 단원 사이의 연결을 한 장의 지도로 보는** 한국어 교육 웹 서비스입니다.

학생이 막혔을 때 문제를 더 주는 대신, 어디서 끊겼는지를 먼저 찾도록 만들었습니다.

- 가로축은 초1 → 고1, 세로축은 수학의 다섯 갈래(수와 연산 · 변화와 관계 · 도형과 측정 · 자료와 가능성 · 논리와 집합)
- 단원을 누르면 **그 단원까지 이어지는 길만** 남고 나머지는 물러납니다
- 단원마다 30초 관문 진단, 대표 오답, 돌아갈 자리, 쉬운 교수 순서
- 학기마다 20~30분 미니 진단과 바로 진도 / 짧은 보충 / 집중 보충 판정
- 로그인·결제·개인정보 수집 없음. 모든 콘텐츠는 정적으로 서비스됩니다.

## 빠르게 실행하기

```bash
npm install
npm run dev
```

http://localhost:3000 에서 열립니다. Node 22.13 이상이 필요합니다.

## 전체 검증

```bash
npm run verify
```

`lint → typecheck → validate → build → test` 를 차례로 실행합니다. 배포 전에는 이 명령이 통과해야 합니다.

| 명령 | 하는 일 |
| --- | --- |
| `npm run lint` | ESLint |
| `npm run typecheck` | TypeScript 타입 검사 |
| `npm run validate` | 콘텐츠 무결성 검사 (ID·연결·범위·금지 항목) |
| `npm run build` | 정적 사이트 생성 (`out/`) |
| `npm test` | 이식 원문 보존·연결 구조·빌드 결과물 검사 |

## 구조

```text
one_math/
├── content/
│   ├── schema.ts          # 모든 콘텐츠의 타입. 필드 뜻이 주석에 있다.
│   ├── index.ts           # 조립부. 연결 그래프·검색·지도 격자를 여기서 계산한다.
│   └── grades/            # e1~e6, m1~m3, h1 — 학년 하나당 파일 하나
├── app/                   # Next.js App Router 화면
│   ├── page.tsx           # 전체 지도
│   ├── grade/[gradeId]/   # 학년 개요 (두 학기)
│   ├── unit/[unitId]/     # 단원 상세
│   ├── strand/[strandId]/ # 갈래 흐름
│   └── guide/             # 사용법과 교육과정 근거
├── components/            # 지도·검색 등 화면 조각
├── scripts/
│   ├── validate-content.ts     # 콘텐츠 무결성 검사기
│   └── port-legacy-content.ts  # 2026-08 검토본 이식 (1회성 기록)
└── tests/                 # node:test
```

### 콘텐츠는 단일 원천입니다

화면·검색·테스트가 모두 `content/grades/*.ts` 하나만 봅니다. 단원 사이의 연결은 자유 서술이 아니라 **단원 ID 참조**(`prereq`)로 적기 때문에, 끊어진 연결이나 앞뒤가 뒤집힌 연결은 테스트에서 걸립니다.

```ts
prereq: [
  { id: "m2-s1-05", why: "기울기와 절편으로 직선을 읽는 눈이 없으면 …" },
],
```

## 콘텐츠를 고칠 때

1. `content/grades/<학년>.ts` 만 고칩니다.
2. `npm run validate` 로 확인합니다. 한 학년만 볼 때는 `node --experimental-strip-types scripts/validate-content.ts --grade=e3`.
3. `npm test` 로 이식 원문이 그대로인지 확인합니다.

`origin: "ported"` 인 단원의 문장(제목·목표·선수개념 서술·오답 신호·교수법·관문)은 2026-08에 교육과정과 대조해 사람이 검토를 끝낸 문구입니다. **바꾸지 않습니다.** 스냅샷 테스트(`tests/ported-content.test.ts`)가 변경을 잡아냅니다. 이 단원들에서 손댈 수 있는 것은 `keywords`, `strand`, `prereq` 뿐입니다.

## 교육과정 기준

2026학년도 기준입니다.

- 초1~초6, 중1, 중2, 고1: 2022 개정 교육과정
- 중3: 2015 개정 교육과정
- 고1: 1학기 공통수학1, 2학기 공통수학2 — 순열·조합·행렬은 공통수학1에만 있습니다.

국가 교육과정은 학년군 성취기준 중심이라 "몇 학기에 어떤 단원"이 문서에 그대로 적혀 있지 않습니다. 이 지도의 학기 배열은 교과서와 EBS 공개 목차를 대조해 정리한 실무 기준이며, 학교와 출판사에 따라 순서가 달라질 수 있습니다. 근거가 확정되지 않은 단원에는 `needsCheck` 를 달아 화면에 '확인' 표시가 나옵니다.

## 배포

정적 파일만 나오므로(`out/`) 어떤 정적 호스팅에도 올라갑니다.

하위 경로에 올릴 때는 기준 경로를 알려 줍니다.

```bash
NEXT_PUBLIC_BASE_PATH=/one-math npm run build
```

GitHub Pages 배포는 `.github/workflows/deploy.yml` 이 `main` 에 푸시될 때 자동으로 처리합니다.

## 만든 과정

2026-08 작성된 「초1~고1 2학기 선수개념 진단 가이드」의 검토 완료본 53개 단원을 문구 그대로 옮기고, 1학기 전체와 고1 공통수학1을 새로 작성해 110개 단원 · 287개 연결로 확장했습니다. 교육과정 배치와 진단 문항 정답은 독립 검토를 거쳤습니다.
